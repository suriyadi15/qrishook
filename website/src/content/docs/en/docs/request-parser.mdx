---
title: Request a parser
description: Capture a debug payload to request a new merchant.
---

Notification formats vary between apps and versions. To request support for a new merchant:

1. Enable notification access for QRIS Hook.
2. Open QRIS Hook and turn on `Debug Mode`.
3. Select the merchant app to capture.
4. Trigger a real or test QRIS notification from that app.
5. Open `Debug Logs`, open the captured log, and tap `Copy`.
6. Create a [Merchant parser request](https://github.com/suriyadi15/qrishook/issues/new?template=merchant_parser_request.yml) issue with:
   - merchant app name
   - package name
   - expected payment details
   - the copied debug payload

:::caution
The debug payload is **required**; requests without one can't be implemented reliably. Before posting, redact sensitive data such as customer names, phone numbers, account identifiers, transaction IDs, and other private information.
:::
