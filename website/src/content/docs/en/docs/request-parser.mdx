---
title: Request merchant support
description: Capture a debug payload to request a new merchant.
---

Notification formats vary between apps and versions. To request support for a new merchant:

1. Enable notification access for QRIS Hook.
2. Open QRIS Hook and turn on `Debug Mode`.
3. Select the merchant app to capture.
4. Trigger a real or test QRIS notification from that app.
5. Open `Debug Logs`, open the captured log, and tap `Request support`.
6. Fill in the expected payment details and a contact (both optional), tick the confirmation, and tap `Send`.

The request is sent straight from the app with the merchant app name, package name, debug payload, QRIS Hook version, and Android version. **No GitHub account is needed.** After it is sent you will see a request number.

:::caution
The debug payload is sent as is. It can contain customer names, amounts, or transaction IDs from the original notification, so prefer a test notification when possible. Requests are only visible to the maintainers.
:::
