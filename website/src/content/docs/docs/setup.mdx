title: Instalasi & setup
description: Pasang APK dan hubungkan ke webhook Anda.

import { Steps } from '@astrojs/starlight/components';

<Steps>

1. **Download APK** terbaru dari [GitHub Releases](https://github.com/suriyadi15/qrishook/releases/latest) lalu pasang di ponsel Android (izinkan instalasi dari sumber ini).

2. **Aktifkan akses notifikasi.** Buka pengaturan Android → *Notification access* → aktifkan **QRIS Hook**.

3. **Tambah webhook.** Ketuk **Tambah webhook**, isi nama, URL, dan bila perlu secret (dikirim sebagai header `X-Webhook-Secret`). Ketuk **Kirim tes** untuk memastikan server Anda membalas 2xx.

4. **Pilih merchant.** Centang aplikasi merchant yang ingin dipantau (lihat [merchant didukung](/docs/merchants/)). Di editor webhook Anda memilih merchant mana yang dikirim ke webhook tersebut; merchant yang tidak dipilih memakai webhook **default**.

5. **Nyalakan `QRIS Hook Active`.** Tanpa ini, notifikasi tidak diproses sama sekali.

</Steps>

:::tip
Gunakan URL HTTPS untuk produksi. Build debug mengizinkan HTTP untuk pengujian lokal; build rilis tidak.
:::
